Conexión segura al motor Python

Escribe la URL HTTPS de tu servidor y su token LOCAL_CHAT_TOKEN. El token queda guardado solo en este dispositivo. Sin servidor, la app responde con su catálogo público sin memoria personal.

La memoria personal se guarda en SQLite del servidor Python, solo tras consentimiento. No se almacena en esta web. No alojes esta página en un hosting público con un token compartido.

Instala o abre Metatrón

Escanea este QR para abrir la app pública. El QR no contiene claves privadas.

Android: menú del navegador → Instalar app / Añadir a pantalla de inicio. iPhone/iPad: Safari → Compartir → Añadir a pantalla de inicio.

Usar con Termux (Android)

Abre Termux y ejecuta el backend local. La app web y el servidor local son cosas distintas: en el teléfono visita http://127.0.0.1:8000/device/ mientras Uvicorn esté corriendo. En Render Free no ejecutes backend desde la terminal; ya está alojado en la nube.

pkg update -y && pkg install python git -y
git clone https://github.com/isaacmtz123490po-arch/metatron-multiplatform-bot.git
cd metatron-multiplatform-bot
python -m venv .venv && . .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
uvicorn src.main:app --host 127.0.0.1 --port 8000

Usar con iSH (iPhone/iPad)

Instala iSH desde App Store. Su Alpine/Linux es limitado; instala dependencias con apk y prueba Python. La app instalable se añade desde Safari, no desde iSH. En iPhone/iPad puedes abrir la URL de nube desde Safari → Compartir → Añadir a pantalla de inicio.

apk update && apk add python3 py3-pip git
git clone https://github.com/isaacmtz123490po-arch/metatron-multiplatform-bot.git
cd metatron-multiplatform-bot
python3 -m venv .venv
. .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
uvicorn src.main:app --host 0.0.0.0 --port 8000

Usar con a-Shell (iPhone/iPad)

a-Shell sirve para comandos locales, pero iOS restringe servicios web persistentes y dependencias Python completas; no es una opción confiable para hospedar este backend. Para la PWA usa Safari y añade la app a inicio. Si a-Shell tiene Python disponible, prueba la instalación, pero puede fallar por las limitaciones de paquetes nativos.
